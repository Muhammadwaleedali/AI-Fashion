## 🚀 How to Use

### Start Development Server
```bash
npm install
npm run dev
```
Visit: `http://localhost:5173`

### Replace Dummy Images
Edit `src/imageUtils.js`:
```javascript
export const dummyImages = {
  before1: 'YOUR_IMAGE_URL',
  after1: 'YOUR_IMAGE_URL',
  // ... etc
}
```

### Customize Colors
Edit `src/index.css`:
```css
:root {
  --primary: #8b5cf6;  /* Your color */
}
```

### Update Content
Edit `src/Landing.jsx`:
- Pricing plans
- Testimonials
- Services
- Contact info
